A static interactive design document for the proposed Aura Engine: a local-first course and life-pipeline concept built from small learning and activity units called atoms.

**Public concept page:** <https://auraofintelligence.github.io/fractal-aura/>

## What the page contains

- a plain-language concept overview
- proposed frontend, data-plane and agent architecture
- example atom, module and pipeline JSON
- a small interactive microtick scheduler demonstration
- privacy, consent and federation design notes
- a phased roadmap

## Open it locally

Open `index.html` in a browser. There is no build step. Web fonts are loaded from Google Fonts.

## Status and boundaries

This repository is a concept page and scheduler demo, not the full system described by its architecture diagrams. Postgres, Qdrant, IPFS/S3 storage, CRDT syncing, wallet identity, on-chain consent, model agents, encrypted export and federation are proposed directions rather than implemented capabilities in this checkout.

Health, wellbeing and schedule examples are design material, not medical advice or evidence that an intervention is suitable for a person.
